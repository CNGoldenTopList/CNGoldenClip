# CNGoldenClip · 金榜速录

安装文件：[安装脚本](https://raw.githubusercontent.com/CNGoldenTopList/CNGoldenClip/main/dist/cngoldenclip.user.js)。适用于已安装 Tampermonkey 的桌面浏览器，站点固定为 `https://cngist.com`。1.1.0 需要先部署配套后端和 `0004_submission_token` 数据库迁移。

## 安装与使用

1. 推荐点击上方「安装脚本」，在油猴页面确认安装；若只显示源码，可在油猴「实用工具」的 URL 安装入口粘贴该链接。也可在该面板导入 `dist/cngoldenclip.user.js`；也可新建脚本，把文件全文粘贴进去并保存。
2. 打开或刷新 B 站搜索页或 BV 视频播放页。搜索卡片的 UP 主和发布日期一行右侧、播放页的「稿件举报」左侧会出现「添加到金榜」。不显示右下角浮条。
3. 每次点击「添加到金榜」，按钮进入 loading 并向后端验证凭据；没有授权或授权失效时自动打开 `https://cngist.com/admin/submission_token`，同时恢复原按钮。管理员点击「一键授权」才签发并写入本机油猴，完成后关闭授权页，返回 B 站再次添加。进入授权页不会创建授权，不显示凭据链接，已撤销授权不再列出。
4. 点视频旁的「添加到金榜」。脚本按 UP 主 UID 匹配金榜玩家，填入视频链接和发布日期。选择已有挑战，再点击保存。
5. 录完后可从油猴菜单「去金榜审核」进入后台。Standard 沿用现有接口自动通过，其余进入待审核；玩家不接受入榜等特殊状态沿用现有补录表单规则。

已配置自动更新。此前手动导入的版本请从安装链接重新安装一次，后续油猴会按更新设置检查并下载新版，也可手动检查更新。名称和 namespace 保持兼容。安装后刷新 B 站搜索页。

## 表单行为

- 玩家匹配检查完整 `bilibiliUids`，兼容旧单 UID 字段。未匹配或存在多份匹配时，显示提示并由管理员选择；不根据 UP 主昵称猜玩家。
- 挑战搜索显示「地图包 / 地图 / 挑战 / 难度」，难度复用网站的精简标签（如 High Std、T7、Low T3），包含地图包级挑战；复用项目的中文、拼音、首字母和英文搜索规则及挑战名显示函数。输入多个关键词用空格分开。标题匹配的地图优先列出，但不会自动确认挑战。
- 输入后点候选项，或用方向键和回车选择。单纯填写搜索文本不算选定。
- 搜索卡片有完整年月日时直接预填。相对日期或缺少年份时，只在打开该视频表单后获取一次视频 HTML，读取 `video:release_date` 并按北京时间转换；请求失败则日期留空、提示打开视频核对，不擅自填今天。管理员可以修改日期。
- 已选玩家和挑战时，合并公开 `/api/records?playerId=…` 与专用授权 `/api/clip/submissions?playerId=…` 返回的记录。后者复用原管理员队列筛选逻辑，包含待审核、拒绝、隐藏及队列中的站内已通过记录；按 ID 合并，再按玩家和挑战匹配，与原版检查范围一致。一行文字显示状态与条数，点「查看记录」展开日期和视频。BV 与分 P 相同则额外提示同一视频。
- 重复提示**不阻止提交**，也不会删除或合并原记录。此功能不是并发去重或数据库约束；只覆盖现有接口返回的数据，回收站记录不在范围内，AV/短链与 BV 的跨格式同视频识别未实现（仍会提示同一玩家的同挑战记录）。
- 检查失败会明确显示“不完整 / 暂不能确认”，不会冒充没有重复；可点「刷新检查」。切换玩家时重新检查，保存后即时更新本地记录和卡片状态。
- 保存期间锁定表单，避免双击；网络失败时保留内容，不自动重试提交。若提示结果不确定，先刷新重复检查或到后台核对，再决定是否重试。
- 本次数量和卡片保存状态保留在当前搜索页内存中，整页刷新后重置。正常搜索翻页会自动为新卡片补按钮。

## 连接方式与权限

授权页只通过指定 URL 访问，不加入网站导航；非管理员提示权限不足。同一个脚本在该页接管真实用户的「一键授权」点击，通过同源 Cookie 请求签发，将响应里的 token 直接写入 GM 存储；网页不显示、传递或保存凭据。不需要保留页面，也不开放 CORS。

写请求仅为 `POST /api/clip/submissions`，以 `Authorization: Bearer <token>` 鉴权，不携带 Cookie。只允许 `playerId,challengeId,videoUrl,achievedAt,rawVideoUrl,playerNote`，不支持批量、建挑战、审核、修改或删除。状态由服务端决定，保留 Standard 自动通过、unwilling 拒绝及 blocked 禁止补录规则。

同一 token 还允许 `GET /api/clip/submissions?playerId=…` 读取所选玩家的重复检查记录，业务范围与原管理员队列一致，仅返回检查所需字段。不允许其他管理读取。

授权默认 90 天，服务器只保存摘要，每次使用检查账户当前状态与管理权限。授权页可撤销自己的每个授权，新授权不撤销其他设备。油猴菜单可清除本机凭据（服务端撤销仍需在授权页操作）。每次打开表单前通过 `GET /api/clip/authorization` 检查 token，网络失败在按钮上提示重试，不误判为授权失效。

`GM_xmlhttpRequest` 获准访问 `www.bilibili.com` 和 `cngist.com`。金榜公开目录与公开成绩请求不携带 token 或 Cookie；token 只发往固定的补录/重复检查端点，拒绝重定向。B 站视频页用于补全发布日期，不后台扫描视频。页面标题与玩家名称均作为文本显示，不执行外部 HTML。

GM API 参考：[Tampermonkey 官方文档](https://www.tampermonkey.net/documentation.php)。

## 开发与验证

在仓库根目录执行：

```powershell
npm install
npm run build
npm test
npm run build
```

`src/` 为源码，`dist/cngoldenclip.user.js` 为可安装的独立打包产物（包含项目搜索依赖，无外部运行时 CDN）。修改源码后须重新生成产物。

本地交互验证：

```powershell
npm run dev
```

打开 `http://127.0.0.1:8279/search`。点击「添加到金榜」，未授权时会打开模拟授权页；点击「一键授权」后关闭该页，回搜索页再次添加记录。验证页用 localStorage 模拟 GM 存储，接口只写进程内存，不连接线上数据库。支持切换公开查询/保存失败、模拟搜索翻页。

验证覆盖：原有 UID 匹配、日期和视频识别；新版 token 存取、双源重复查询、部分失败提示、写入超时不重试和权限边界；网站授权页按钮在本地 GM 存储替身下验证。真实 Tampermonkey 扩展仍需安装后联调；未向线上提交测试记录。

## 发版

1. 修改源码，在 package.json 中递增 version。
2. 运行 npm install、npm test、npm run build。
3. 将源码、package.json / package-lock.json 和 dist 下两个产物一起提交并推送到 main。
4. 可选创建同版本 Git tag / GitHub Release，记录变更说明。

构建从 package.json 读取唯一版本号。dist/cngoldenclip.meta.js 用于检查版本，dist/cngoldenclip.user.js 用于安装及下载更新。main 上的 dist 代表已发布版本；只改源码而不构建不会更新管理员的脚本。两个文件由同一次提交发布，不应手工编辑。

## 接口兼容

固定连接 https://cngist.com。公开查询使用 `GET /api/catalog`、`GET /api/records?playerId=…`；待审核等记录查询使用专用 `GET /api/clip/submissions?playerId=…`，提交使用专用 `POST /api/clip/submissions`。授权页通过网站会话调用 `GET/POST/DELETE /api/admin/submission-token`，该接口不接受专用 token。网站改变接口字段时需同步检查脚本。
